# 🔄 End-to-End Workflow

```text
User Enters URL
        ↓
Website Scraping Starts
        ↓
Selenium Loads Website
        ↓
HTML Content Extracted
        ↓
BeautifulSoup Cleans DOM
        ↓
Clean Text Sent to AI
        ↓
AI Generates:
    • Questions
    • Answers
    • Keywords
    • Insights
        ↓
JSON Response Returned
        ↓
Streamlit Renders Dashboard
```

| Layer              | Technology     |

| LLM Models         | openai         |
| Backend Logic      | Python         |
| Environment Config | python-dotenv  |
